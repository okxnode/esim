# 联盟链接接入指南

> 这份文档回答一个问题：**怎么把比价表里的「购买」按钮变成能赚钱的链接。**

---

## 一、先搞清楚三件事

### 1. 技术接入只要改一个文件

全站所有购买链接都来自 **`data/plans.json` 里 `brands[].buy_url` 这一个字段**。

```
data/plans.json  ──build──▶  /plans.json  ──fetch──▶  compare.js 渲染「购买」按钮
                                          └────────▶  single.html 渲染品牌页「前往官网」按钮
```

改一处，比价表和品牌评测页**同时**生效。不需要碰 JS、不需要碰 HTML。

### 2. 真正花时间的是"拿到链接"，不是"贴上链接"

| 阶段 | 耗时 | 说明 |
|---|---|---|
| 申请 → 通过 | **3 天 ~ 4 周** | 各平台差异大，见下表 |
| 贴上链接 | **1 分钟** | 一条命令 |

所以别等网站写完才去申请——**现在就去提交申请**，审核期间继续写内容。

### 3. 有个前置条件：网站得先上线

几乎所有联盟平台都会审核你的站点。他们要看到：

- 域名能打开（不能是 `localhost` 或空白页）
- 有**真实内容**（不是纯采集站）—— 你现在 26 篇原创内容已经够了
- 有**联盟披露声明** —— 本站已内建（页脚 + 文章页 notice）
- 有**隐私政策**页 —— ⚠️ **本站还缺这个**，见第四节

> **结论**：先推 GitHub → 部署 Cloudflare Pages → 拿到线上地址 → 再提交申请。

## 二、按这个顺序申请

排序依据：**佣金率 × cookie 时长 × 通过难度**。先申请回报最高的。

### 第一梯队（优先，一周内全提交）

| 品牌 | 佣金 | Cookie | 申请入口 | 备注 |
|---|---|---|---|---|
| **Saily** | 15% | 30 天 | `saily.com/affiliate` | Nord Security 旗下，通过率高，有中文页 |
| **Gigago** | 30% | 90 天 | 官网 footer → Affiliate | 佣金最高但品牌新，审核可能慢 |
| **Holafly** | 10% | **365 天** | 走 Impact 平台 | cookie 一年，长尾收益最佳 |

### 第二梯队（同期提交，审核较慢）

| 品牌 | 佣金 | Cookie | 申请入口 | 备注 |
|---|---|---|---|---|
| **Airalo** | 10% | 30 天 | 走 **Impact** 平台 | 最大品牌，必需 |
| **Nomad** | 10-15% | 30 天 | 走 **Impact** 平台 | 与 Airalo 同平台，一次注册可申请多个 |
| **Ubigi** | 10% | 60 天 | 官网 contact | 企业背景，流程偏正式 |

### 特殊：聚合平台（注册一次，多个品牌）

- **Impact** —— Airalo、Holafly、Nomad 都在这，**优先注册这个**
- **Awin** —— Holafly 的备用通道
- **ShareASale** —— 部分小品牌

> 注册 Impact 一次，然后在其内部逐个申请品牌，比每个品牌单独注册快得多。

## 三、技术操作（拿到链接之后）

### 3.1 看当前状态

```bash
cd ~/work/esim-ltd
make aff-list
```

输出：

```
品牌         接入     buy_url
------------------------------------------------------------------------
Airalo     · 官网原址 https://www.airalo.com/
Saily      · 官网原址 https://saily.com/
...
------------------------------------------------------------------------
0/6 个品牌已接入联盟链接
```

### 3.2 贴入联盟链接

```bash
python3 scripts/set_affiliate.py saily "https://saily.com/aff/你的追踪码"
```

脚本会：
1. 把 `buy_url` 换成你的追踪链接
2. 把 `affiliate_link_ready` 自动置为 `true` → **品牌页那句"联盟链接接入中"的灰字提示会自动消失**
3. 校验链接是 https、且没误指回站内页

一次接入多个：

```bash
python3 scripts/set_affiliate.py \
  airalo  "https://airalo.pxf.io/xxxx" \
  holafly "https://holafly.sjv.io/xxxx" \
  saily   "https://saily.com/aff/xxxx"
```

### 3.3 常见的链接形态

各平台给你的链接长这样，**原样粘贴即可**：

```
https://airalo.pxf.io/c/1234567/1234567/12345          ← Impact 短链
https://saily.com/aff/ABCDEF?ref=yourdomain            ← 参数式
https://www.gigago.com/?aff=12345                      ← 参数式
https://click.linksynergy.com/deeplink?id=xx&mid=yy    ← Awin/Rakuten
```

脚本用这些特征判断"是否已带追踪参数"：`aff=` `ref=` `utm_source=` `pxf.io` `sjv.io` `linksynergy` 等。
如果你的平台链接形态特殊、体检报"看不出追踪特征"，属于**建议修**而非必须修，确认链接正确就忽略。

### 3.4 撤销 / 回退

```bash
python3 scripts/set_affiliate.py --revert saily    # 单个
python3 scripts/set_affiliate.py --revert all      # 全部退回官网原址
```

### 3.5 验证 + 上线

```bash
make check      # 构建 + 29 项测试 + 联盟体检
make serve      # 浏览器里点一下「购买」按钮，看跳转对不对
```

**上线前务必手动点一遍**：追踪链接可能因为复制不全、或平台做了域名跳转而失效。
浏览器打开比价页 → 点「购买」→ 确认落地页是你申请的那个品牌，且 URL 里带追踪参数。

⚠️ **不要用 `curl` 验证追踪链接**：部分平台会防风控，`curl` 的结果不代表真实点击。
用真实浏览器点。

## 四、上线前必补：隐私政策页

**这是当前唯一的合规缺口。** 联盟平台审核和 Google 都可能要求。

建一个 `content/privacy.md`：

```markdown
+++
title = "隐私政策"
description = "本站的数据收集与 Cookie 使用说明"
date = 2026-09-24
+++

## 我们收集什么

本站为静态站点，不设服务器数据库，不主动收集你的个人信息。

## Cookie

本站自身不设置追踪 Cookie。但页面中的联盟链接指向第三方平台，
这些平台可能通过 Cookie 记录你的来源，用于结算佣金。
你可以随时在浏览器设置中清除或禁用 Cookie。

## 第三方分析

本站使用 Cloudflare Web Analytics，该服务不采集个人身份信息、不使用 Cookie。

## 联盟披露

本站通过联盟链接获得佣金。你通过链接下单不会多付一分钱，
佣金用于维持站点运营。推荐结论不受佣金影响。

## 联系方式

如有疑问，请联系 <你的邮箱>。
```

然后在 `hugo.toml` 的菜单里加上「隐私政策」，并放进页脚。

## 五、合规红线（踩了会被平台封号 / Google 降权）

| 红线 | 说明 |
|---|---|
| **必须披露** | 每篇带联盟链接的文章都要有披露。本站用 `has_affiliate = true` 触发，**新写的评测页别忘加** |
| **必须 `rel="sponsored"`** | 已内建。`make audit` 会扫产物里的外链，漏了会告警 |
| **不许隐藏联盟身份** | 不要用短链伪装、不要写"点击查看"而不说明是广告 |
| **不许自点击** | 自己点自己的联盟链接刷单 = 封号，无例外 |
| **不许宣称"绕网络管制"** | 只做「出国旅行上网省钱」叙事。中国大陆 eSIM 本页不涉及交易 |
| **价格必须标注更新日** | `_updated` 字段，测试会校验 |
| **不承诺未经证实的效果** | 没实测过的网速/覆盖别写 |

## 六、收益怎么算

以比价站典型转化为例：

```
月 PV 30,000  ×  点击购买率 8%  ×  下单转化率 3%  ×  客单价 $20  ×  佣金 12%
= 30,000 × 0.08 × 0.03 × 20 × 0.12 ≈ $173 / 月
```

**关键变量不是 PV，是「点击购买率」。** 提升办法：

1. 比价表把「购买」按钮放在操作列第一位置（已做）
2. 每篇目的地页 / 评测页都要有购买入口，而不是只在比价页（已做）
3. 文章里自然穿插"我去日本用的是 XX"这类个人使用场景
4. 优先推**高佣金 + 长 cookie** 的品牌（Gigago 30%/90天、Holafly 10%/365天）

> Holafly 的 365 天 cookie 意味着：用户今天看到你的文章、**一年后**才下单，佣金依然算你的。
> 这类品牌值得在内容里多给曝光。

## 七、常见问题

**Q: 申请被拒了怎么办？**
大概率是网站内容量不够或没有隐私政策页。补齐后隔 2-4 周再申请。部分平台（Airalo/Impact）对内容站比较友好，可以先用它们建立记录。

**Q: 可以同时接多个品牌吗？**
可以，而且应该。不同用户偏好不同品牌，全接了才有最大覆盖面。本站比价表设计就是为多品牌服务的。

**Q: 用户用了广告拦截器，佣金会丢吗？**
会。这是行业常态，不用过度优化。提升内容质量比对抗拦截器有效得多。

**Q: 链接失效了怎么发现？**
`make audit` 会检查形态，但不检查"是否 404"。建议每月手动抽查一次，
或后续加一个定时任务跑链接存活检查（可作为下一步自动化）。

**Q: 联盟后台显示有点击但没转化？**
正常。eSIM 转化率行业区间约 1-5%。如果长期为 0，检查落地页是否真的能下单（有些地区会被限制）。
